## 最重要の報告：343件は227件だった

指示書に従い343件からランダム15件を図書カードで確認する過程で、**その中に著作権とは無関係な事例が混ざっていることに気づいた**。島崎藤村「芽生」、与謝野晶子「みだれ髪」等、著作権が切れているはずの作家の作品が「本文取得不可」に分類されていた。

調べたところ、本文ファイルの命名規則に**`{作品ID}_{ファイルID}.html`だけでなく`{作品ID}.html`（ファイルID無し）という別パターンが存在し、これまでのglob検索が見落としていた**ことが判明した。343件のうち116件がこのパターンで実在した。

この116件を修正して再処理したところ：
- 116件のうち大半が、**別の既知の問題（旧式HTML形式）に該当**し、結局処理は失敗する
- しかし「失敗の理由」が正しくなった（「本文が無い」ではなく「旧式形式で未対応」）
- 真に本文取得不可なのは **227件**（343件ではない）
- 旧式HTML形式は当初把握していた37件ではなく **142件**（4倍近い規模）

修正後の227件を同じ手順で検証し直し、全件が外部URLへのリンクを持つ、真に著作権存続中の作品であることを確認した。

**指示書の言葉を借りるなら、これは「1件の推論を343件に広げていた」ことの延長線上にある問題だった。** ランダム抽出という検証手順そのものが、この命名規則のバグを見つける役に立った。
